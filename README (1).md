# Dibuja y Adivina

Juego multijugador de dibujo y adivinanzas con Node.js, sin dependencias.

## Publicarlo
1. Sube `server.js`, `package.json` y la carpeta `public` (que contiene `index.html`) al mismo repositorio.
2. En un servicio que ejecute Node.js, configura el comando de inicio como `npm start`.
3. Usa Node.js 18 o superior. No lo publiques en GitHub Pages: el juego necesita ejecutar `server.js`.
4. Abre la URL pública del servicio. Cada jugador debe abrir esa misma URL, escribir su nombre y usar exactamente el mismo código de sala.

## Probar en tu computadora
Ejecuta `npm start` y abre `http://localhost:3000`.
